## 1. 훈련생 모집이나 선발 시 훈련생의 역량 수준을 고려하는 평가 체계를 갖출 것

### □ 테스트 환경 개별 세팅 가능

| 구분 | 주요내용 |
|---|---|
| 테스트 커스터마이징 | 관리자는 문제은행(객관식·주관식, 문제 코드 자동 채번)을 기반으로 시험을 구성하고, **제한시간·재응시 횟수·응시 대상 과정**을 시험별로 설정하여 평가하고자 하는 훈련생의 역량을 맞춤형으로 설계 가능. 제한시간은 서버가 만료 시각을 계산·관리하며 **만료 시 자동 제출** 처리되어 공정한 평가 보장. 재응시는 설정 횟수 초과 시 서버가 거부. `<시험 생성·설정 화면>` |
| 참가자 목록 확인 | 시험이 시작되면 **응시자 목록·응시 상태·남은 시간·이상행위 감지 횟수**를 모니터링 화면에서 실시간 파악 가능. **입·퇴장 기록은 서버에 append-only 로 저장**(수정·삭제 0건, 실증 완료)되고, 응시 녹화본은 서버에 저장되어 **권한 인증된 스트리밍**으로 추후 검토 가능. `<평가 모니터링 화면>` `<응시 녹화 재생 화면>` |
| 공지·알림·개별 메시지 | 관리자는 훈련생 전원 또는 과정 단위로 시험 안내를 **공지**하여 일괄 관리 가능. **개인 지정 알림**으로 개별 안내를 전송하고, 감독 중 부정행위 의심 발견 시 **응시자에게 경고 발송**으로 즉각 제재 가능. 훈련생-교강사 간 1:1 문답은 튜터링·Q&A 기능으로 지원. `<공지 등록 화면>` `<감독 경고 발송 화면>` |
| 테스트 결과 다운로드 | 훈련생의 평가 결과 데이터는 채점 화면에서 일괄 확인하고 **파일로 다운로드**하여 취합·관리 가능 (현재 CSV 제공, **엑셀(xlsx) 전환 진행 중** — Apache POI 도입 완료). `<시험 결과 다운로드 화면>` |
| 사전 모의 테스트 | **(진행 중)** 성적에 반영되지 않는 연습 모드 시험으로 응시 환경 사전 점검 지원 예정. |

| 수동·혼합 채점 | 서술형 등은 수동채점 화면에서 채점하며, 자동+수동 **혼합 채점** 운영 가능. **채점 → 성적 확정 → 변경 이력** 절차를 갖추고, **사유 없는 점수 변경은 서버가 거부**하여 채점 투명성 확보. `<수동채점·성적확정 화면>` |

|---|---|

## ※ 외부 솔루션 연동 / 기관 협의 필요 항목 (본 문서 미기재)

아래는 자체 구현 대상이 아니어서 본 기능 소개에 포함하지 않았다. 기관 의사결정(외부 솔루션 연동 / 범위 제외) 후 반영한다.

- 3중 모니터링(웹캠·모니터·모바일), 화면·웹캠 강제 공유, 듀얼 모니터 차단
- QR 원격 신분증 확인, 안면인식 출석, OTP·산업인력공단 연동, 휴대폰 본인인증(PASS 등)
- 화상강의 대규모 동시접속, 브라우저 IDE(코딩 실습 샌드박스)·100+ 언어 지원
- AI 챗봇, AI 이탈률 예측(EPS류), 오토스케일링·클라우드 인증
