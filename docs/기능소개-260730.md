## 1. 훈련생 모집이나 선발 시 훈련생의 역량 수준을 고려하는 평가 체계를 갖출 것

### □ 훈련생 자격 검증 및 계정 관리 체계

| 구분 | 주요내용 |
|---|---|
| **신규 가입 승인** | • 신규 가입 시 관리자가 승인 후에 로그인 가능. 신규 가입자는 **승인 대기** 상태로 생성되어 관리자의 승인 이전에는 **로그인 자체가 차단**되며, 미승인 계정이 훈련 데이터에 접근할 수 없도록 원천 통제<br>`<가입 승인 화면>` |
| **훈련생/강사 관리** | • 관리자는 **훈련생·강사·관리자 3개 권한군**의 전체 목록과 상세정보를 통합 조회할 수 있으며, 각 계정을 **승인대기·활성·정지·탈퇴 4단계 상태**로 관리하여 훈련 중도 이탈자 및 퇴직 강사의 접근 권한을 즉시 회수 가능<br>`<훈련생(왼)과 강사(오) 관리 화면>` |

### □ 역량 수준을 판별하는 평가 설계 체계

| 구분 | 주요내용 |
|---|---|
| **문제 세트 랜덤 배정** | • 하나의 시험에 문제 세트를 여러 개 편성하고 응시 시작 시점에 응시자별로 무작위 배정하여, 동일 시험에도 응시자마다 다른 문항을 접하도록 구성. 문항 출제 순서 자동 섞기를 병행하여 인접 응시자 간 답안 공유 가능성을 구조적으로 차단<br>`<실제 학생 시험 진행 화면>` |
| **난이도별 자동 출제** | • 각 대분류/중분류/소분류 및 태그로 출제 범위를 지정하고 난이도별 문항 수를 설정하면 문제은행에서 조건에 맞는 문항을 자동으로 편성<br>• 훈련생의 역량 수준을 단계적으로 판별할 수 있도록 상·중·하 난이도 비율을 시험 목적에 맞게 설계 가능<br>`<자동 출제규칙 설정 화면>` |
| **응시 조건 상세 설정** | • 제한 시간, 응시 가능 기간, 재응시 허용 여부 및 최대 횟수를 시험별로 개별 설정하여 평가 목적에 맞는 환경 구성. 사전연습 모드를 제공하여 훈련생이 실제와 동일한 환경을 미리 경험할 수 있으며, 연습 응시 결과는 성적에 반영되지 않도록 분리<br>`<시험 관리 상세조건>` |
| **결과 공개 시점 제어** | • 성적 공개를 즉시/채점 완료 후/지정 일시/비공개 4가지로 설정하여, 채점이 끝나기 전 미확정 점수가 노출되는 것을 방지<br>`<시험 목록 화면>` |

### □ 부정행위 방지 및 채점 체계를 통한 평가 공정성 확보

| 구분 | 주요내용 |
|---|---|
| **응시자 본인 확인** | • 시험 입장 시 본인인증 절차를 거치도록 설정할 수 있어 대리 응시를 차단하고, 훈련생 본인의 역량이 정확히 측정되도록 보장 |
| **응시 환경 통제** | • 시험별로 웹캠 요구, 화면 전환 차단, 복사·붙여넣기 차단 옵션을 개별 적용하여 응시 중 외부 자료 참조 및 답안 유출 방지<br>`<시험 응시 화면>` |
| **입퇴장 기록 및 감독** | • 응시자의 입장·퇴장 시각과 응시 중 발생한 이벤트를 서버에 기록하여 실제 응시 여부를 사후 검증 가능<br>• 관리자·강사는 모니터링 화면에서 현재 응시 인원과 진행 상황을 실시간 파악하고, 이상행위 감지 시 경고 기록이 남아 사후 제재 근거로 활용<br>`<시험로그 모니터링 화면>` |
| **자동·수동 채점** | • 객관식 문항은 제출 즉시 자동 채점되어 결과가 산출되며, 주관식·서술형은 담당 강사만 채점할 수 있도록 권한을 제한<br>• 채점 결과는 성적 확정 절차를 거쳐야 훈련생에게 공개되며, 확정 이후의 점수 정정 내역은 이력으로 보존되어 임의 수정 방지<br>`<자동/수동 채점 화면>` |
| **결과 데이터 산출** | • 성적 결과를 엑셀 파일로 일괄 다운로드할 수 있으며, 성적 시트와 정정 이력 시트가 함께 제공되어 취합·검증 효율화<br>`<성적 엑셀 다운로드>` |

## 2. 기업 현장의 상시적 수요를 훈련과정에 반영하는 체계적인 시스템을 갖출 것

### □ 학습자료 자산화를 통한 지속적 콘텐츠 고도화

| 구분 | 주요내용 |
|---|---|
| **문제 은행 관리** | • 제작한 평가 문항을 문제은행에 축적하여 데이터베이스화하고, 대분류·중분류·소분류·난이도·태그 체계로 분류 관리<br>• 축적된 문항은 여러 시험에서 반복 재사용할 수 있으며, 조건 검색으로 필요한 문항을 즉시 확보하여 신규 과정 개설 시 출제 소요 시간 대폭 단축<br>• 문제은행 전체를 엑셀로 내려받아 외부 검토 및 백업 관리 가능<br>`<문제 은행 목록 화면>` |
| **학습 콘텐츠 관리** | • 교육 콘텐츠(영상·문서)를 플랫폼에 등록하여 일괄 관리하며, 각 콘텐츠를 과정·과목·차시에 연결하여 체계적으로 배치<br>• 훈련생의 추가 자료 요청 발생 시 관리자·강사가 콘텐츠를 즉시 등록·배포하여 현장 수요에 신속 대응<br>`<콘텐츠 등록 화면>` |

### □ 훈련과정 편성 및 상시 개편 체계

| 구분 | 주요내용 |
|---|---|
| **과정-과목-차시 편성** | • 훈련과정을 과정 → 과목 → 차시의 3단계 구조로 편성하여, 산업 수요 변화에 따라 특정 과목·차시만 선택적으로 교체·보강 가능<br>• 과정별 훈련 기간·정원·운영 상태를 관리하여 개설부터 종료까지 전 주기 통제<br>`<과정 관리 화면>` |
| **훈련생 수요 수렴** | • 설문조사 기능으로 과정 만족도 및 강의 평가를 수집하고, 문항별 응답 분포와 주관식 의견을 집계하여 차기 과정 설계에 반영<br>• 설문 결과는 엑셀 리포트로 산출되어 운영 회의 및 개선 근거 자료로 활용<br>`<설문 결과 화면>` |
| **실무형 과제 운영** | • 현장 과제를 등록하여 훈련생이 파일·링크·텍스트 형태로 결과물을 제출하도록 하고, 강사가 개별 피드백을 제공하여 실무 역량 배양<br>`<과제 제출/피드백 화면>` |
| **🆕 채용 수요 기반 직무 역량 안내** | • 목표 직무별로 현장에서 요구되는 역량을 단계별 로드맵으로 정리해 훈련생에게 제시하고, 훈련생이 이미 학습한 자료와 대조하여 아직 채우지 못한 역량을 식별<br>• **개발 직군 10종**(백엔드·프론트엔드·풀스택·모바일·데브옵스·데이터·AI/ML·정보보안·QA·게임)을 지원하여 훈련생의 진로 선택 폭 확보<br>• 화면에 산출 근거를 명시하여 참고 자료임을 분명히 표기<br>`<직무 로드맵 화면>` |

## 3. 개별 훈련생의 수준이나 요구를 훈련과정에 반영하여 맞춤식 훈련 과정을 설계할 수 있는 역량을 갖출 것

### □ 학습 데이터 수집 및 현황 분석

| 구분 | 주요내용 |
|---|---|
| **학습 데이터 자동 수집** | • 훈련생의 콘텐츠 학습 진도, 출결 현황, 평가 성적, 과제 제출 여부가 시스템에 자동 축적되어 개인별 학습 상태를 상시 파악<br>• 수집된 데이터는 훈련 종료 후에도 보존되어 자체 성과평가 및 운영체계 고도화의 기반 자료로 활용<br>`<학습 데이터 자동수집 화면>` |
| **관리자 종합 대시보드** | • 훈련생·강사 인원, 과정 진행 현황, 평가 진행·채점 현황, 출결 확정 및 이수 현황, 미응답 문의 건수를 한 화면에서 종합 파악<br>• 위험 신호 영역을 통해 조치가 필요한 항목을 우선 노출하여 선제적 대응 지원<br>• **과정별 진도율과 훈련 기간 경과율을 나란히 비교**하여, 기간 대비 진도가 뒤처진 과정을 즉시 식별<br>`<관리자 종합 대시보드1> <관리자 종합 대시보드2>` |
| **강사 대시보드** | • 담당 과정, 채점 대기 중인 시험·과제, 응답 대기 문의, 시험 감독 현황을 확인하여 지도 우선순위 판단<br>• 강사는 본인이 담당한 과정의 데이터만 조회 가능하도록 통제<br>• **관리자와 동일한 산출 기준을 적용**하여 같은 과정에 대해 관리자와 강사가 서로 다른 수치를 보는 일이 없도록 설계<br>`<강사 대시보드1> <강사 대시보드2>` |
| **데이터 산출** | • 대시보드 현황, 성적, 설문 결과, 문제은행을 엑셀 파일로 내려받아 보고 및 분석에 활용 |

### □ 개인별 학습 현황 제공 및 수준별 대응

| 구분 | 주요내용 |
|---|---|
| **훈련생 개인 대시보드** | • 훈련생은 본인의 학습 현황을 파악할 수 있는 '내 대시보드' 기능을 통해 주도적인 학습 가능<br>• 수강 중인 과목을 바로 확인하고 '이어서 학습' 기능을 통해 다음 학습 자료로 원클릭 이동이 가능<br>• 본인의 출석 현황을 직접 확인하며 스스로 학습 참여도 관리 가능<br>• **같은 과정 수강생 대비 본인의 학습 진도 위치를 시각적으로 제시**하여 학습 동기 유지 (타 훈련생의 성명은 노출하지 않고 진도 순위만 익명 표시)<br>`<훈련생 대시보드 기능>` |
| **수준별 평가 운영** | • 난이도별 자동 출제로 훈련생 수준에 맞는 평가지를 구성하고, 재응시 허용 설정을 통해 미달 훈련생에게 보완 학습 후 재평가 기회 제공 |
| **🆕 AI 학습 도우미** | • 훈련생이 학습 중 궁금한 점을 입력하면 **해당 과정에 등록된 학습 자료를 근거로 즉시 답변**하여, 강사 답변을 기다리지 않고 학습을 이어갈 수 있도록 지원<br>• 답변에 **참고한 학습 자료 링크를 함께 제시**하여 훈련생이 원문을 확인할 수 있으며, 자료에서 다루지 않는 내용은 **'과정 자료 밖의 일반 지식'으로 명확히 구분 표시**하여 수업 내용과 혼동되지 않도록 통제<br>• AI 답변으로 해결되지 않는 질문은 **[강사님께 전달]** 버튼으로 담당 강사 Q&A에 자동 등록되어, 질문이 누락 없이 사람에게 이어짐<br>`<AI 학습 도우미 화면>` |

- **AI 답변의 한계를 함께 기재**했다. 학습 자료 밖의 내용은 화면에서 구분 표시된다는 점을 명시하여, 심사 시 "AI가 틀린 답을 하면?"이라는 질문에 답할 수 있게 했다.
- **"AI가 과제를 배부한다"고 쓰지 않았다.** 초안 생성까지가 AI이고 배부 확정은 강사다. 실제 동작과 다르게 쓰면 시연에서 어긋난다.
- 훈련생 진도 순위 기능은 **"타 훈련생 성명 미노출"**을 함께 적었다. 개인정보 관련 질의를 미리 차단하기 위함이다.
